# مدل تشخیصِ چهره — MobileFaceNet (ArcFace) — `w600k_mbf.onnx`

این فایل مستقیماً از انتشار رسمی InsightFace دانلود شده (بدون تغییر)، برای
استفادهٔ **غیرتجاری** در این سامانهٔ داخلیِ کارخانه — طبق تصمیم صاحب پروژه.

| | |
|---|---|
| **نام دقیق مدل** | `w600k_mbf.onnx` — بخشِ تشخیصِ چهره (recognition) از بستهٔ `buffalo_sc` |
| **منبع** | https://github.com/deepinsight/insightface/releases/download/model-zoo/buffalo_sc.zip (انتشار رسمیِ InsightFace؛ همان آدرسی که کتابخانهٔ پایتونیِ خودشان هم استفاده می‌کند) |
| **مجوز** | کد InsightFace: MIT. **مدل‌های آموزش‌دیده (همین فایل): فقط برای مصارف غیرتجاری/پژوهشی.** برای استفادهٔ تجاری باید با خودِ InsightFace مجوز جداگانه گرفت. این پروژه تجاری نیست، پس مجاز است. |
| **معماری** | MobileFaceNet، آموزش‌دیده با تابع خطای ArcFace روی مجموعهٔ WebFace600K |
| **ابعاد ورودیِ ONNX** | نامِ گره: `input.1` — شکل `[N, 3, 112, 112]` (batch پویا، RGB، CHW) |
| **نوع دادهٔ ورودی** | `float32` |
| **نرمال‌سازیِ پیکسل** | `(pixel − 127.5) / 128` برای هر کانال RGB (بازهٔ خروجی تقریباً [−1, 1]) — نیازمندِ چهرهٔ هم‌ترازشده (5 نقطه) در قاب 112×112، دقیقاً مطابق قالبِ استانداردِ ArcFace |
| **نامِ خروجی** | `516` |
| **ابعاد بردارِ خروجی** | 512 (پس از این، در کد ما L2-normalize می‌شود) |
| **حجم فایل** | ۱۳٫۶ مگابایت |
| **هزینهٔ تخمینیِ inference** | چند ده میلی‌ثانیه روی WASM تک‌رشته‌ای در یک گوشی میان‌ردهٔ ۲۰۱۸ (به‌مراتب سبک‌تر از ResNet) |
| **مناسبِ استفادهٔ تجاری؟** | **خیر** — طبق مجوزِ رسمیِ InsightFace. اگر روزی این پروژه تجاری شد، باید یا از InsightFace مجوز گرفت، یا با یک مدلِ دیگر (مثلاً SFace از OpenCV Zoo، یا مدل‌های خودآموزِ facex-engine) جایگزین شود. |

منبعِ مجوز: https://github.com/deepinsight/insightface#license
